## Recommended learning path

1. Start with the root README and workspace setup.
2. Explore the admin template and production templates.
3. Review plugin and deployment patterns before shipping production work.
4. Use SSR/SEO guidelines for landing pages and product marketing.
5. Standardize on a template for each product type: SaaS, portfolio, ecommerce, internal tool, and app-lite.
